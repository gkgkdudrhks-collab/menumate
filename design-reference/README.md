# 디자인 레퍼런스

누런 종이 바탕에 두꺼운 외곽선과 흐림 없는 하드 섀도를 쓰는 **레트로 인쇄물 스타일**의 HTML/CSS 묶음입니다.
특정 서비스에 매이지 않은 범용 자료로, 새 화면을 만들 때 시각 언어를 골라 쓰기 위한 것입니다.

## 사용 목적

- 시각적 레퍼런스: 색상, 타이포그래피, 3px 외곽선, 하드 섀도, 종이 질감, 테이프·도장 장식, 카드 회전, 반응형 레이아웃, 버튼 인터랙션
- 데모 페이지의 문구와 정보 구조를 그대로 가져다 쓰기 위한 자료가 아님
- 기능 코드(인증, API 호출, 상태 관리)와 이 레퍼런스 원문을 섞지 않음
- 디자인 적용과 UX 개선은 별도 단계로 다룸

## 파일

| 파일 | 설명 |
|---|---|
| `reference-index.html` | 디자인 검토용 데모 페이지. 컴포넌트가 실제 배치된 모습을 한 화면에서 봅니다. 본문 문구는 자리표시용 예시이며, 구조와 클래스 이름은 CSS와 짝이 맞습니다. |
| `reference-styles.css` | 스타일 원문. 색상값, 크기, 간격, 테두리, 그림자, transform, 애니메이션, 미디어 쿼리 등 디자인 값을 임의로 수정하지 않았습니다. |

## 디자인 토큰

`reference-styles.css` 의 `:root` 에 정의돼 있습니다.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--ink` / `--ink-soft` | `#28231e` / `#56483a` | 글자와 테두리 |
| `--paper` / `--paper-dark` | `#f8efd9` / `#dfcba4` | 종이 배경, 트랙 바닥 |
| `--cream` | `#fff9ea` | 카드 바탕 |
| `--mustard` | `#f3b941` | 상단 바, 주요 버튼 |
| `--rust` / `--rust-dark` | `#bd5535` / `#873b2d` | 강조, 경고 |
| `--green` / `--green-light` | `#557347` / `#87a961` | 진행·긍정 |
| `--navy` | `#283947` | 어두운 패널 |
| `--line` | `3px solid var(--ink)` | 기본 외곽선 |
| `--hard-shadow` | `7px 8px 0 var(--ink)` | 흐림 없는 그림자 |

## 데모에 없지만 CSS에 정의된 것

아래 클래스는 스타일만 있고 데모 페이지에는 배치돼 있지 않습니다. 필요할 때 꺼내 쓰면 됩니다.

- 상태: `.is-selected`, `.is-winner`, `.is-loading`, `.error`
- 사용자 영역: `.user-chip`, `.user-fallback`, `.logout-button`, `.tiny-note`
- 별도 문서 페이지: `.legal-body`, `.legal-main`, `.legal-paper`, `.legal-note`, `.legal-updated`

## 포함되지 않은 것

이미지와 웹폰트는 이 묶음에 들어 있지 않습니다. 데모를 열면 아래가 비어 보이거나 대체 폰트로 표시됩니다.

- `/assets/*.webp` — 히어로·카드 이미지
- `/assets/east-sea-dokdo-hero.ttf` — `@font-face` 가 참조하는 손글씨 폰트
- `/favicon.svg`

레이아웃과 색, 간격을 확인하는 데는 지장이 없습니다.

## 사용 시 주의

1. 이 폴더는 **디자인 레퍼런스**로만 유지합니다.
2. 구현 폴더로 원문 전체를 복사해 기능 코드와 합치지 않습니다.
3. 실제 적용 시에는 대상 프로젝트의 HTML 의미 구조와 기능을 유지한 채 필요한 디자인 토큰과 컴포넌트 패턴만 선별해 옮깁니다.
