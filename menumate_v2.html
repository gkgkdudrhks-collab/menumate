Supabase Cloud DB 연동 상태

연동 방식 안내

Supabase 연결 정보(SUPABASE_URL, SUPABASE_ANON_KEY)는 보안을 위해 Vercel 환경변수에서만 관리됩니다.
HTML 코드나 브라우저 저장소에는 저장되지 않습니다.

Vercel 환경변수 등록 방법
  1. Vercel 대시보드 → 프로젝트 선택 → Settings → Environment Variables
  2. SUPABASE_URL = https://your-project.supabase.co 추가
  3. SUPABASE_ANON_KEY = eyJ... 추가
  4. 저장 후 Redeploy (재배포) 하면 자동 연결됩니다.
Supabase SQL Editor 테이블 생성 쿼리 
CREATE TABLE IF NOT EXISTS public.menumate_users (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    role TEXT DEFAULT '멤버',
    avatar TEXT DEFAULT '🧑‍💻',
    likes JSONB DEFAULT '[]'::jsonb,
    dislikes JSONB DEFAULT '[]'::jsonb,
    dna JSONB NOT NULL DEFAULT '{"spice":0,"greasy":0,"meat":0,"sweet":0}'::jsonb,
    allergies JSONB DEFAULT '[]'::jsonb,
    recent_meals JSONB DEFAULT '[]'::jsonb,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);
ALTER TABLE public.menumate_users ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow public read-write" ON public.menumate_users FOR ALL TO public USING (true) WITH CHECK (true);

* Supabase 대시보드의 SQL Editor에 위 쿼리를 붙여넣고 RUN을 실행해 테이블을 생성하세요.

LLM API 연동 상태

연동 방식 안내

Gemini API Key(GEMINI_API_KEY)는 보안을 위해 Vercel 환경변수에서만 관리됩니다.
HTML 코드나 브라우저 저장소에는 저장되지 않습니다.

Vercel 환경변수 등록 방법
  1. Vercel 대시보드 → 프로젝트 선택 → Settings → Environment Variables
  2. GEMINI_API_KEY = AIza... 추가
  3. 저장 후 Redeploy (재배포) 하면 자동 연결됩니다.
  4. 미설정 시 MenuMate 내장 알고리즘이 자동으로 작동합니다.
